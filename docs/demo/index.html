电压、不平衡度、迭代数都由 web_demo.js（MoonBit js 后端产物）算出： build_topology + sweep 前推回代，页面只画图。
后两组面板是预计算网格 - 构建时把每一档都跑完，滑块只切档。原因和 foc 那边一样： MoonBit 的 js 产物是整段 IIFE、没有导出，wasm-gc 产物也只导出 _start， 页面拿不到可调用的句柄。负荷倍率档是页面里唯一需要重建网的参数：每档用 DistNode::make + Phasor::scale 换掉注入功率再求解。
